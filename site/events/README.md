This folder was created because we had multiple events that required a google form. So we couldn't have a single event-request.html (which is the base event-request override).
Keeping the event-request.html as the base template, we created two new files: event-request-jpl.html and event-request-smallsat.html.

So we copied event-request.html to both event-request-jpl.html and event-request-smallsat.html and then updated the form links in each file.
