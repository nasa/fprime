27 //! \class AtomicQueue
28 //! \brief A lock-free MPMC FIFO circular buffer with fixed-size buffer storage
29 //!
30 //! This queue stores fixed-size message buffers using memcpy semantics. Each slot
31 //! contains an embedded buffer (not just a pointer). The circular buffer uses atomic
32 //! sequence numbers for lock-free coordination between multiple producers/consumers.
33 //!
34 //! Features:
35 //! - O(1) enqueue/dequeue with bounded CAS retries
36 //! - Embedded buffer storage (memcpy on send/receive)
37 //! - Optional blocking enqueue via Os::CountingSemaphore (platform-agnostic)
38 //! - Uses only word-size atomics (no DWCAS), portable to all architectures
39 //!
40 //! Pre-allocates memory for slots and buffers during create()
41 //! \note Power-of-2 capacity uses fast bitwise AND; other sizes use modulo (~5-20% slower)
42 //!
43 //! \warning Position Counter Wrap-Around: The m_enqueuePos and m_dequeuePos counters are
44 //! FwSizeType (platform word size). On 64-bit platforms (FwSizeType=U64), wrap-around
45 //! is functionally impossible (~584 years at 1 GHz). However, on 32-bit platforms
46 //! (FwSizeType=U32), wrap-around occurs after 2^32 operations (~1.2 hours at 1M ops/sec).
47 //! The algorithm remains correct after wrap (sequence numbers prevent ABA), but applications
48 //! with sustained high throughput on 32-bit systems should be aware. FwSizeType=U32 is
49 //! used (instead of forcing U64) to support platforms with 32-bit native word size where
50 //! 64-bit atomics may not be lock-free or require expensive emulation.
