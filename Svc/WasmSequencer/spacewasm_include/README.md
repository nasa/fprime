# Vendored `spacewasm.h`

`spacewasm.h` is the C API header for the `spacewasm_c_api` crate, generated by
cbindgen and shipped inside the published crate at `include/spacewasm.h`. It is
committed here **verbatim** (byte-for-byte identical to the crate release) so it
can be diffed cleanly against future upstream versions. The `.clang-format` in
this directory sets `DisableFormat: true` so the repository formatter never
rewrites it.

## Version

Kept in lockstep with the `spacewasm_c_api` / `spacewasm` versions pinned in
[`../fprime_spacewasm/Cargo.toml`](../fprime_spacewasm/Cargo.toml).

## Refreshing after a version bump

After changing the pinned version in `../fprime_spacewasm/Cargo.toml` and
updating the lock file (`cargo update -p spacewasm_c_api --precise <version>`),
copy the header out of the extracted crate source verbatim:

```sh
VER=<version>   # e.g. 0.6.4
SRC="$(cargo metadata --format-version=1 --manifest-path ../fprime_spacewasm/Cargo.toml \
       | python3 -c 'import json,sys; \
         print(next(p["manifest_path"] for p in json.load(sys.stdin)["packages"] \
                    if p["name"]=="spacewasm_c_api"))')"
cp "$(dirname "$SRC")/include/spacewasm.h" ./spacewasm.h
```

Do not hand-edit or reformat the copied file.
